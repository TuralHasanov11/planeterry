# Production Process


## Step 1 - Generate the script

Use ChatGPT to create a script with:

- A strong opening.
- Simple vocabulary.
- One educational objective.
- A clear narrative.
- A satisfying ending.


## Step 2 - Create a character reference sheet

Generate the character from different angles and expressions.

Your character reference sheet should define:

- Exact colors.
- Eye shape.
- Body proportions.
- Clothing and accessories.
- Facial expressions.
- Voice/personality.
  Save these references. Reuse them in every future video.

## Step 3 - Create individual scenes

Don't ask a video model to generate the entire 30-second video in one prompt. Instead, generate approximately 4–6 second clips.

For example:

```
A cute little green baby dinosaur named Max,
with a round head, big expressive brown eyes,
short arms and a small yellow belly.

Max is standing in a colorful preschool garden.
He discovers a mysterious red box.

High-quality stylized 3D animated children's film,
soft studio lighting, vibrant colors,
friendly facial expression, smooth animation.

Vertical 9:16 composition.
Keep the character design consistent with
the provided reference image.

Camera: medium shot, gentle camera movement.
No text, no watermark.
```


## Step 4 - Generate narration

Example:

```
"Wow! Look what I found! It's a red apple! Can you say red?"
Use a consistent voice.
```


## Step 5 - Combine the clips

Add:

- Narration.
- Background music.
- Sound effects.
- Subtitles, where appropriate.
- Smooth transitions.

## Step 6 - Review manually

Check that:

- Characters don't change appearance.
- No distorted faces or limbs.
- No unnatural movement.
- No inappropriate imagery.
- Narration matches the animation.
- Audio is comfortable and not excessively loud.

## Step 7 - Export

Recommended starting settings:

| Setting      | Value                                  |
| ------------ | -------------------------------------- |
| Aspect ratio | 9:16                                   |
| Resolution   | 1080 × 1920                           |
| Frame rate   | 30 FPS                                 |
| Format       | MP4                                    |
| Codec        | H.264                                  |
| Duration     | 20–40 seconds for initial experiments |
